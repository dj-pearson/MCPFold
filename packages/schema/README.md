# @mcpfold/schema

The config schema + validation for **[mcpfold](https://www.npmjs.com/package/mcpfold)** — the typed
shape of the canonical mcpfold config, with validation and helpful error messages.

This is an internal building block. To use mcpfold, install the CLI:

```sh
npm install -g mcpfold
```
