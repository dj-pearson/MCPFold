# @mcpfold/core

Core engine behind **[mcpfold](https://www.npmjs.com/package/mcpfold)** — the canonical MCP config
model, tool-curation logic, and sync planning. Pure, dependency-light, and client-agnostic.

This is an internal building block. If you just want to use mcpfold, install the CLI:

```sh
npm install -g mcpfold
```
