# @mcpfold/secrets

Secret-reference resolution for **[mcpfold](https://www.npmjs.com/package/mcpfold)** — lets your
config point at secret _references_ (env, native OS keychains, and more) that resolve at sync time,
so real key values never get hardcoded into client config files.

This is an internal building block. To use mcpfold, install the CLI:

```sh
npm install -g mcpfold
```
